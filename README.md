# Vitta Saúde

Site demonstrativo de uma clínica fictícia, criado para o portfólio de Sabrina Lima.

## Funcionalidades
- Escolha de especialidade, profissional, data e horário.
- Simulação de agendamento com confirmação na página.
- Identidade visual e logo com símbolo de saúde em SVG.

## Executar
Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript, sem instalação.

## Demonstração
https://vitta-saude-sabrina.limaucello.chatgpt.site

O site está privado no momento. Não há consultas reais nem envio de dados para uma clínica. A foto é ilustrativa e foi gerada para este projeto.
